# 音乐窗鼠标行为修正

日期：2026-10-27。组件版本：`2026.10.27p1`。本轮落实 [鼠标行为分析](MOUSE_BEHAVIOR_ANALYSIS.zh-CN.md) 中已有证据支持的修正，并遵循用户后续约束：**不实现“每周推荐”列表**。

## 行为变化

| 区域 | 修正后的行为 |
| --- | --- |
| 外框边框和皮肤空白右键 | 按用户后续要求增加“音乐窗”“下载管理”两项，勾选当前页面；选择后复用顶部标签的切换路径，取消不切换 |
| 下载分类空白、横幅和帮助按钮右键 | 不弹外框菜单，不播放歌曲，不改变内嵌网页；网页自己的菜单仍由 IE/WebView2 处理 |
| 下载中任务双击 | 有效行才响应；下载中暂停，等待/暂停/失败任务走开始或重试；不会播放远程 URL |
| 已下载播放图标 | 单击在同一行图标内释放后播放；拖出、取消和捕获丢失不播放；双击的第二次消息不重复触发图标播放 |
| 已下载行双击 | 播放有效行；空白单击清除选择，空白双击不播放旧选择 |
| 下载右键菜单 | 先将焦点交给列表；右击未选行改为单选，右击已选行保留多选；下载中多选保留开始/暂停可用且不显示全选 |
| 键盘菜单键 | 定位到选中行，必要时先滚入可见范围；无选择不弹菜单 |
| 下载分类 | 重复点击当前分类保留选择、焦点和滚动位置 |
| 表头 | 下载中不能排序；已下载同一表头按下并释放才排序；列边界两侧 10 像素不排序，不提供双击自动列宽 |
| 提示与光标 | 下载状态、歌曲元数据、已下载播放图标有提示；播放图标及可用外框按钮使用手形 |
| 滚轮和滚动条 | 累计不足 120 的滚轮增量，遵循系统行数或整页设置；按住箭头/轨道连续滚动，拖出暂停，释放停止 |
| 分隔条 | 中央 5×5 按钮收起分类栏到 0，再次点击恢复此前宽度；拖动按起点偏移计算 |
| 取消操作 | 分隔条、滚动滑块的 Esc、右键、WM_CANCELMODE、捕获丢失恢复起点；外框消息过滤器先取消内部捕获，不直接隐藏窗口 |

普通 Delete 仍删除记录或任务。已下载分类的 Shift+Delete 进入“删除文件”，与原版命令分流一致。

边框菜单是用户指定的新交互，不作为原版还原结论。按钮和内容矩形不响应边框菜单；子窗向父窗传递的 `WM_CONTEXTMENU` 也不会打开它。外框的键盘菜单请求提供同样两项。`WM_CANCELMODE` 在取消皮肤拖动/按压后继续交给系统，使系统菜单能够正常退出。

## 底部链接

默认文字为“千千静听使用技巧”，默认地址为 `http://ttplayer.qianqian.com/help.html?f=client`。地址来自原版资源及初始化路径，不表示该历史网站当前可用。本轮未访问历史服务。

`AddBrowserHyper` 追加链接，`ClearBrowserHyper` 清空自定义链接并恢复默认项。短文本按实际宽度命中并右对齐；长文本在皮肤预留矩形内裁剪。绘制下划线、手形和当前标题提示。点击通过 `ShellExecuteW` 打开外部关联程序，不再导航内嵌页面。

多链接短文本等待 3 秒后纵向切换；长文本先水平往返，端点停留 1 秒。动画帧间隔 40 毫秒。悬停归位并暂停，离开恢复。按住链接后即使拖出，轮播仍暂停，避免释放前目标被计时器换掉；捕获取消后重新计算计时。隐藏/销毁窗口停止计时。网页更新链接集合时取消旧链接的按压状态。

原版确认的新增路径：`0040914B`、`004091B4`、`004092FC`、`0040935C`、`0040989E`、`0040C181`、`0040DD02`、`0040DD7C`。从已有全量反编译提取后，八个函数的机器码均与用户指定 x/z 两套目标一致。复核脚本及逐范围哈希在 `out/mouse-fix-20261027/verify_link_evidence.py` 和 `evidence/link-function-identity.json`。这些是本地静态复核，不是新的 REA 会话 Evidence ID；其它鼠标路径的 REA 引用保留在前述分析报告。

## 删除文件与主程序接入

新增 `download_file_actions.cpp`，使用 `SHFileOperationW` 的 `FO_DELETE + FOF_ALLOWUNDO`，由 Shell 处理文件操作界面。允许撤销是 API 请求，不保证所有路径都能进入回收站。取消、部分失败或无法确认文件已不存在时，保留相应下载记录；只移除此次操作后确认消失的媒体文件记录。

主程序的 `resolve_associated_lyric` 回调只返回已知且实际存在的关联歌词，尊重 NoLyric 状态，不猜测同名 `.lrc`。存在关联时，用户可选择同时删除、只删歌曲或取消。BSTR 由 DLL 释放，回调在 UI 线程执行。`BrowserClient` 转发时保留原宿主 context，并复用关闭状态检查。

该回调是 `ttp_browser_host` 的可选尾部扩展，ABI 仍为 1。`adjust_window_rect` 和歌词回调分别按完整指针边界判断 `size`，不读取旧宿主分配之外的字节。旧 EXE 仍可加载新 DLL，但完整歌词关联功能需要本轮配套 EXE。

`AddRecomdSound` 保留参数及来源检查，合法调用返回 `S_FALSE`，不保存推荐项；`ClearRecomdList` 合法调用返回 `S_OK` 并保持无操作。没有新增推荐列表、宿主推荐回调或外框推荐菜单。
